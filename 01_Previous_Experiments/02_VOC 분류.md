
# 02. VOC 자동 분석 시스템

> 개인 샌드박스 환경에서 진행한 VOC 분석 자동화 실험

## 1. 실험 배경 및 목적

### 1.1 실험 배경

- 기존 VOC 분석 업무에서 개선하고자 했던 문제
- 수작업 분석 과정의 개선 필요성
- 자동화를 시도하게 된 배경

### 1.2 실험 목적

- 페이드 게시물 탐지 및 검수
- 사용자 질문에 맞는 원문 VOC 추출
- 소비자 반응 분류 및 주요 이슈 요약
- 반복 작업과 오류에 대응하는 처리 방식 검토

---

## 2. 1차: VOC 분석 기능 구현

### 2.1 개발 환경

| 구분 | 내용 |
|---|---|
| 개발 형태 | Jupyter Notebook |
| 주요 언어 | Python |
| 분석 데이터 | 짐빔 관련 VOC |
| AI 연동 | Google GenAI API |
| 입력 데이터 | Excel |
| 세부 환경 | 실제 실행 기록 확인 후 기재 |

### 2.2 기능 구현 과정

#### STEP 01. 입력 데이터 처리

- Excel 파일의 데이터 구조 확인
- 분석 대상 열 설정
- 분석 범위 및 조건 설정
- 데이터 처리 방식 구현

#### STEP 02. 페이드 탐지

- 협찬 및 광고 관련 표현 탐지
- 규칙 기반으로 1차 후보 선별
- AI를 이용한 추가 판정
- 검수 대상 구분

#### STEP 03. 질문 기반 VOC 추출

- 사용자가 분석할 질문 입력
- 질문에 직접 답하는 원문 확인
- 원문과 연결된 답변 및 맥락 추출
- 근거 유효성 검증

#### STEP 04. 소비자 반응 분류 및 요약

- VOC별 소비자 반응 분류
- 긍정·부정·중립 및 불명확 반응 구분
- 주요 카테고리 및 이슈 정리
- 원문 근거에 기반한 요약

#### STEP 05. 오류 및 작업 관리

- 작업 진행 상황 확인
- API 호출 오류 대응
- 완료 결과 저장 및 재개
- 검수 및 결과 관리

## 3. 2차: Streamlit 웹 애플리케이션

### 3.1 웹앱 개발 배경

노트북에서 구현한 분석 기능을
브라우저에서 사용할 수 있도록 확장한 이유 작성

### 3.2 개발 환경

| 구분 | 내용 |
|---|---|
| 개발 형태 | Python 웹 애플리케이션 |
| 웹 프레임워크 | Streamlit |
| AI 연동 | Google GenAI API |
| 작업 상태 저장 | SQLite 및 파일 저장 |
| 실제 서버 환경 | 확인 후 기재 |

### 3.3 웹앱 주요 기능

- 엑셀 파일 업로드
- 분석 대상 열 연결 및 분석 조건 설정
- 페이드 탐지 및 질문 기반 VOC 추출
- 분석 진행률 및 오류 확인
- 작업 일시정지 및 재개
- 저장된 작업 불러오기
- 결과 확인 및 CSV 다운로드

### 3.4 1차 노트북 대비 변경사항

| 구분 | 1차 | 2차 |
|---|---|---|
| 사용 환경 | Jupyter Notebook | 웹브라우저 |
| 입력 방식 | 노트북 설정 | 웹 화면 |
| 작업 관리 | 노트북 기반 | 서버 작업 관리 |
| 결과 공유 | 파일 중심 | 작업 코드 및 웹 화면 |
