# 사전 실험 및 기술 검토

본 페이지는 DI그룹 LLM 프로젝트 추진 이전에
개인 샌드박스 환경에서 진행한 실험 기록입니다.

## 기존 실험 목록

### 1. RAG 시스템 구축
RAG를 검토한 배경과 실제 구현 과정, 실험 결과를 기록합니다.

### 2. 인트라넷 배포
기존 시스템의 웹 환경 배포 과정과 확인 사항을 기록합니다.

### 3. Gemma 기반 LLM 실험
모델 선정 배경과 테스트 과정, 결과 및 한계사항을 기록합니다.

## 자료 활용 목적

기존 실험의 수행 과정과 시행착오를 공유하고,
신규 프로젝트의 수행계획 수립에 참고자료로 활용합니다.
