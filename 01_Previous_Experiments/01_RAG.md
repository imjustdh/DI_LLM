
# 01. 사내 생활백서 RAG 구축 실험

## 1. 실험 개요

### 실험 목적

사내 생활백서 PDF를 기반으로 사용자의 질문과
관련된 정보를 검색하고, 검색한 문서를 근거로
답변을 생성하는 RAG 시스템을 구현하고자 함.

CPU 환경에서 기본적인 검색 시스템을 검증하고,
이후 Gemma 모델과 연결하는 구조를 실험함.

### 실험 대상

- 문서: 뉴엔AI 생활백서 v3.0
- 개발 방식: Python 및 Jupyter Notebook
- 실행 환경: CPU 기반
- 주요 기능: PDF 추출, 문서 분할, 벡터화, 검색 및 답변 생성

---

## 2. 실험 설계

### 2.1 기본 설계 방향

별도 대형 모델 없이도 전체 검색 흐름을
검증할 수 있도록 문자 기반 해시 벡터 방식을 사용함.

향후 실제 의미 검색을 위한 임베딩 모델로
교체할 수 있도록 구조를 구성함.

### 2.2 전체 처리 과정

1. PDF 문서 불러오기
2. 페이지별 텍스트 추출
3. 페이지 정보가 유지되도록 문서 분할
4. 추출한 텍스트의 벡터화
5. 벡터 및 문서 데이터 저장
6. 사용자 질문에 대한 관련 문서 검색
7. 검색 결과를 활용한 LLM 답변 생성

---

## 3. 실제 구현 과정

### STEP 01. PDF 데이터 추출

- 55페이지의 생활백서 PDF 활용
- 페이지별 텍스트 및 제목 추출
- 추출한 문서의 페이지 정보를 메타데이터로 보존
- 텍스트가 부족한 페이지 별도 확인

### STEP 02. 문서 분할 및 벡터화

- 최대 청크 길이: 900자
- 청크 중복 범위: 120자
- 페이지별 문서 정보 유지
- 한국어 문자 n-gram 기반 해시 벡터 사용
- 2,048차원 벡터 생성

### STEP 03. 검색 기능 구현

- 사용자 질문을 벡터로 변환
- 코사인 유사도 기반 검색
- 관련 문서 상위 5개 반환
- 검색 결과에 문서 제목 및 페이지 정보 표시

### STEP 04. Gemma 연결

- Docker llama-server 연결을 위한 호출 기능 구현
- 검색 문서를 답변 생성 프롬프트에 포함
- 근거 문서의 페이지 번호를 표시하도록 설정
- 노트북에 답변 생성 실행 예시 기록

---

## 4. 테스트 결과

### 문서 처리 결과

- 원본 PDF: 55페이지
- 벡터화 대상: 52페이지
- 생성된 청크: 52개

### 검색 테스트

9개의 사전 구성된 질문으로 검색 기능을 평가함.

| 평가 항목 | 측정 결과 |
|---|---:|
| 평가 질문 | 9개 |
| Recall@5 | 1.000 |
| MRR@5 | 0.778 |

모든 평가 질문에서 기대한 페이지가
상위 5개 검색 결과에 포함됨.

단, 소규모 자체 평가 결과이므로
실제 운영 환경의 검색 성능을 의미하지는 않음.

### 답변 생성

사내 동호회 지원 기준에 관한 질문을 입력하여
근거 문서의 페이지 번호가 포함된
답변 생성 예시를 확인함.

## 5. 실험의 한계

- 기본 실험은 의미 검색 모델이 아닌
  문자 기반 해시 벡터 사용
- 평가 질문 수가 제한적임
- 텍스트가 부족한 일부 PDF 페이지 존재
- 다수 사용자 환경에 대한 검증 없음
- 검색 및 생성 품질에 대한 추가 검증 필요

---

## 6. 후속 검토사항

- EmbeddingGemma 기반 검색 실험
- 기존 해시 방식과 검색 성능 비교
- 텍스트 추출이 어려운 페이지 처리
- Qdrant 벡터 DB 적용
- Docker 기반 LLM 연결 및 응답 지연 측정
- 문서 접근 권한 및 개인정보 관리 검토

위 항목은 노트북에 기재된 후속 계획이며,
실제 수행이 확인된 결과와는 구분함.

## 7. 신규 프로젝트 참고사항

이번 실험은 소규모 환경에서 사내 문서를
활용한 RAG의 기본 구조를 검증한 사례임.

향후 프로젝트에서는 다음 내용을 참고할 수 있음.

- 사내 문서 처리 및 검색 시스템 구성
- CPU 기반 실험 환경 설계
- 문서 출처를 유지하는 데이터 처리 방식
- LLM과 검색 시스템의 연결
- 검색 성능 평가 방법

실제 사내 서비스 구축 시에는
검색 모델, GPU 활용, 동시 사용자 처리,
보안 및 운영 조건을 추가 검토해야 함.
