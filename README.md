# DI_LLM
DI그룹 특화 LLM 구축을 위한 개발 및 검토 히스토리

1. 추진 아젠다: DI그룹 특화 LLM 구축 / 사내 업무 활용이 가능한 자체 AI 환경 구축
2. 목적: 보안이 필요한 사내 데이터를 내부 환경에서 활용하고, GPT·Gemini와 유사한 사용성을 제공하며, 향후 그룹 업무에 맞게 확장 가능한 기반을 구축
3. 전체 구축 Flow: 모델 조사 → 모델 선정 → 하드웨어 검토 → 테스트 환경 구축 → RAG/업무 연계 → UI 구축 → 사용자 테스트 → 운영 기준 수립 → 단계적 확대
4. 테스트 및 검토 과정: 기존 RAG 구축, 인트라넷 배포, Gemma 계열 모델 테스트, 모델별 성능/자원 비교, 업무 적용 테스트 등 지금까지 했던 내용을 시간순으로 기록
5. 구축 방향
시스템 관점: LLM, GPU, 경량 모델, RAG, UI, 대화 컨텍스트, 서버 구성
업무 관점: 실제 어떤 업무에 사용할지, 팀별 활용 방식, 업무 데이터 연결 방식, 향후 에이전트 확장 가능성
6. 운영 및 사용성
UI: GPT/Gemini처럼 익숙한 채팅형 인터페이스 \n
사용자: 팀 공용 계정 + 개인 계정 운영 검토 \n
데이터: 초기부터 지나친 제한보다는 활용 가능 범위를 넓게 두고 보안 수준에 따라 통제 \n
대화: 한 대화창에서 처리 가능한 입력량, 장기 대화 시 성능 변화, 새 대화 생성 시 이전 컨텍스트 반영 방식 조사 \n
협업: 팀 단위 지식과 개인 대화/작업 영역을 어떻게 분리할지 검토
7. 필요 하드웨어: 후보 모델별 필요 GPU 메모리, 동시 사용자 수, 추론 속도, 경량 모델 병행 여부 등을 기준으로 산정
8. 추진 일정: 9월 말 수행계획서 v0.1 → 모델/하드웨어 세부 검증 → UI 및 운영 프로토타입 → 업무 적용 테스트 → 고도화
9. 업무분장: 시스템 / 운영으로 크게 나누고 각 담당자가 조사한 내용을 GitHub에 누적
